# M. Faizan Raza — Creative Portfolio

Updated with the 51 distinct images provided in FR.zip. The old six fictional project examples have been replaced by eight collections of actual uploaded artwork.

## Open the site
Open `index.html` in any modern browser. Keep the `assets/` folder next to `index.html` so the images load correctly. For hosting, upload the entire folder (index.html, assets, and optional JSON).

## Project section
The eight collections group the uploaded archive into JAC Motors, Changan, Deepal, Forland, Fingtap Network Visuals, Fingtap Digital, THA Europe Travel & Visa, and THA Europe Recruitment. Click a collection to browse each original design in a full-resolution gallery; use arrow buttons/keyboard and thumbnails. All 51 unique designs are included. W2.jpeg was a byte-for-byte copy of W1.jpeg and has been removed; Recruitment now contains one artwork.

- `assets/preview/`: optimized WebP previews for responsive gallery loading
- `assets/original/`: original unmodified JPEG files from the upload
- `project-collections.json`: human-readable collection metadata

To change the gallery titles, collection descriptions, or image order, edit the `collectionData` object in the JavaScript near the bottom of `index.html`, and the corresponding project cards in the Work section. No build step is required.

## Other features
Default dark-blue theme with light-mode toggle, reactive hero, scroll reveals, parallax project cards, About canvas, sticky career timeline, and contact buttons.

Fonts use Google Fonts when an internet connection is available, with system fallbacks otherwise.

## Compatibility
The site has responsive layouts for mobile, tablet, laptop, and desktop, including touch-friendly gallery and navigation controls. The gallery switches to a single-artwork layout for THA Recruitment. Motion respects the reduced-motion system setting. Use a modern browser with support for the HTML dialog element; keep the `assets/` directory next to `index.html`.

On touch devices, the About-section portrait initially allows normal page scrolling. Use **Draw here** to enable finger drawing, then **Done drawing** to return to scrolling.
